# DSP graph implementation plan

> Use subagent-driven development for independent modules.
> Continue through implementation, verification, review, and integration without continuation prompts.

**Goal:** Compile and execute bounded feed-forward PCM graphs with explicit transformations and merge latency.

**Architecture:** Keep shared graph intent in Core and compiled plans in the DSP adapter crate.
Prepare buffers and delay state before processing.
Keep the existing session reducer as the only control authority.

**Tech stack:** Rust 1.98.1, existing core formats, serde, and the pinned SHA-256 implementation.

**Spec:** [SPEC.md](../../SPEC.md), sections 8.1–8.4 and Appendix E.2.
Cover T10, DSP-01, DSP-03, DSP-04, DSP-05, and ARCH-05.
T11 owns PEQ, partitioned convolution, and SRC implementations.

## Shared contract

`GraphDocument` carries schema version 1, typed nodes, edges, and one selected output node.
Use `NodeId` as an opaque string validated like the existing domain IDs.
Ports declare PCM rate, mono/stereo layout, f64 processing, and the maximum processing quantum.
Keep all graph buffers within an explicit `GraphBudget`.
Admit at most 128 nodes, 256 edges, and 8192 frames per quantum.
Use the existing 256 MiB default buffer ceiling.
These are initial implementation limits, not claims about every future graph.

Initial `NodeKind` variants are input, output, bypass, gain, delay, matrix, sum, and meter.
Delay uses integer frames.
Matrix coefficients map each declared input channel to each declared output channel.
Sum accepts only matching rate, layout, and precision.
Unsupported fractional compensation and multirate merges reject explicitly.
Future PEQ, convolution, and SRC nodes require T11 implementations and qualification.

`compile(&GraphDocument, &CompileContext) -> Result<CompiledPlan, GraphError>` validates and resolves intent.
`CompiledPlan` exposes content hash, ordered schedule, formats, latency, tails, resources, and transformations.
`GraphError` identifies the failing node or edge and a shared error code.
Canonical hashing must ignore input node-list order and include semantic parameters and implementation version.
Reject duplicate IDs, missing ports, disconnected required nodes, cycles, and non-finite parameters.
Never insert a converter or reduce processing quality silently.

`PreparedGraph::prepare(CompiledPlan, Epochs) -> Result<PreparedGraph, GraphError>` allocates all processing state.
`PreparedGraph::process(&mut self, input: &[f64], output: &mut [f64]) -> Result<usize, GraphError>` returns frames.
Processing performs no allocation, deallocation, file access, logging, or locking.
Reject mismatched spans and non-finite input or output.
Preserve state across successive quanta and compatible source joins.
`PreparedGraph::finish` drains the declared tail once, then becomes terminal.
Expose reset only for an explicit new stream epoch.

`GraphTransaction` binds a prepared plan to expected revision and source/device epochs.
Preparation failure preserves the active graph.
Commit rejects stale or consumed tokens.
Keep retired graph resources available for disposal outside the processing thread.
The engine adapter submits activation through the existing session reducer.
Do not create a second graph revision authority in a controller or binding.

## Integration rulings

Reuse core sample-domain and opaque-identity definitions when lifting graph intent into the shared command model.
Use a checked finite graph scalar so command equality remains valid and serialized numbers keep their shape.
Keep exact request equality and the existing 1024-receipt window.
Share immutable history entries to avoid cloning full graph documents on each session mutation.
Bound graph intent before retaining it.
Keep control-history memory separate from prepared audio-buffer budgets.
Retain one shared terminal graph record after completion outside the ordinary receipt window.
This preserves settled replay after long operations without evicting the latest 1024 ordinary requests.
Expose failed activation recovery explicitly and block unmute until successful graph activation.
Advance the stream generation on failed activation when its counter permits advancement.
Carry the actual engine activation frame through the acknowledgement API.
Count host conversion buffers, active kernels, candidates, and retired kernels in peak audio admission.
Report integer conversion and quantization explicitly around processed f64 graphs.
Apply shared volume safety after graph processing and before a single declared quantization step.
Preserve graph state at compatible queue joins.
Use explicit muted rebuffering when a seek, pause fallback, or topology change resets graph history.
Do not claim reconstructed DSP history or physical pause continuity.
